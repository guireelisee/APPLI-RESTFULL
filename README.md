## APPLI RESTFULL (Développement à base de composants)

### Objectif

Développer une application _Restfull avec Laravel_, en utilisant _WSO2 ou apache kafka_ pour ETL _(Extract, Transform, Load)_ pour se connecter/synchroniser sur _deux bases données_.

### Tâche

-   Développez un service restful avec Laravel pour exposer les données de clients depuis la base de données à travers l’ETL
-   Implémentez des opérations CRUD.
-   Testez les service avec un client .
-   Utilisez _prometheus_ pour surveiller les performances du service
